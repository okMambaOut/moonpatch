# Changelog

## 0.1.0 - 2026-08-13

- Parse, validate, and serialize unified text patches with stable diagnostics.
- Generate deterministic bounded LCS diffs.
- Apply and reverse multi-file patches transactionally in memory.
- Support explicit hunk relocation, LF/CRLF, final-newline state, and path changes.
- Provide inspect, diff, apply, reverse, and demo CLI workflows.
- Verify 26 tests on portable targets and configure native CI verification.
